# User Notification System

Multi-module проект на Spring Boot.

## Модули

- `user-service` — REST API для управления пользователями.
- `notification-service` — микросервис уведомлений.

## Функциональность

При создании или удалении пользователя `user-service` отправляет событие в Kafka.

Событие содержит:

- тип операции: `CREATED` или `DELETED`;
- email пользователя.

`notification-service` получает событие из Kafka и отправляет email:

- при создании: `Здравствуйте! Ваш аккаунт на сайте ваш сайт был успешно создан.`
- при удалении: `Здравствуйте! Ваш аккаунт был удалён.`

Также `notification-service` предоставляет REST API для ручной отправки уведомления.
